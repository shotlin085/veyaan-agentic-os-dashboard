# Complete Page Inventory (16 Core Pages)

1. **Home Command Centre** (`src/app/page.tsx`) — Flagship Page 1. Hero command prompt, priority alert strip, VEYAAN System Topology Map, Department capacity grid, internal cost routing overview.
2. **Personal Assistant** (`src/app/assistant/page.tsx`) — Flagship Page 2. Hermes SSE conversation stream, structured Requirement Interview Cards, inline Approval Cards, Context Rail, Voice Composer.
3. **Workflow Studio** (`src/app/workflows/page.tsx`) — Flagship Page 3. React Flow visual graph canvas, 20-node library, node inspector, dry-run test console, draft/publish lifecycle.
4. **Projects Control** (`src/app/projects/page.tsx`) — Project list, phase badges, requirement trees, progress bars, budget allocation.
5. **Department Management** (`src/app/departments/page.tsx`) — 5 company operating divisions (Product, Research, Dev, UI/Design, QA/Security), workload metrics, manager identities.
6. **Agent Management** (`src/app/agents/page.tsx`) — Registered agents, active state badges, model policy, success rate, cost spend today.
7. **Agent Factory** (`src/app/agents/factory/page.tsx`) — Step-by-step wizard for generating sub-agent contracts, tool policies, and safety checks.
8. **Prompt Studio** (`src/app/prompts/page.tsx`) — Monaco Markdown editor for prompt files, variable bindings, model playground, version diffs.
9. **Skill Studio** (`src/app/skills/page.tsx`) — SKILL.md manifest editor with YAML frontmatter, tool dependencies, and non-coder wizard.
10. **Memory Console** (`src/app/memory/page.tsx`) — pgvector RAG memory search, namespace browser, memory proposals, source evidence.
11. **Approval Centre** (`src/app/approvals/page.tsx`) — Governance inbox, risk/impact ratings, step-up confirmation, approve/reject handlers.
12. **QA Centre** (`src/app/qa/page.tsx`) — Release confidence dashboard (98.4%), WCAG 2.2 AA audit, Playwright E2E suite, defect tracking.
13. **Logs & Observability** (`src/app/logs/page.tsx`) — Correlation log timeline, event payload viewer, secret redaction, replay context.
14. **Sandboxes & JCode** (`src/app/sandboxes/page.tsx`) — Active coding sandboxes, terminal stream output, Git diff inspector, preview frame.
15. **Models & Costs** (`src/app/costs/page.tsx`) — Internal provider spend, token latency, fallback routing, daily budget caps.
16. **Notification Centre** (`src/app/notifications/page.tsx`) — Action required drawer, priority alert cards, channel preferences.
17. **Organization Settings** (`src/app/settings/page.tsx`) — Internal team session profile, RBAC roles, secret keys, security policy. Zero SaaS pricing/billing.
